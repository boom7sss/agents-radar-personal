2. **DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data** · `ArXiv`
   **做什么：** 仅用许可数据从零训练1B分层推理模型，在英语和丹麦语上取得前沿性能。
   **为什么读：** 开源许可数据训练范式与1B规模前沿性能兼具，对开源LLM社区有明确价值。
   [阅读论文](http://arxiv.org/abs/2608.13517v1)

3. **QuoteBench: How Matched Scores Can Hide Command-Path Failures** · `ArXiv`
   **做什么：** 揭示LLM编码智能体命令生成与执行传输之间的失败边界，提出精确验证基准。

   [阅读论文](http://arxiv.org/abs/2608.13547v1)

4. **Vero: Can AI Agents Build Formally Verified Software Repositories?** · `ArXiv`
   **做什么：** 首个评估AI在多模块代码库上联合生成实现与机器检查证明的基准。
   **为什么读：** 推动可信AI生成软件的关键一步，填补函数级验证到仓库级验证的空白。
   [阅读论文](http://arxiv.org/abs/2608.13522v1)

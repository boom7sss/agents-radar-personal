## 7. Trend Signals

**For AI agent developers, the community feedback reveals five durable trends:**

1. **Trust is the #1 feature gap.** Users repeatedly report silent drop of messages, hallucinated connection status, cron fabrication, and false success indicators across OpenClaw, IronClaw, Hermes, NanoBot, and NanoClaw. *Action:* treat delivery acknowledgement, failure surfacing, and status verification as first-class product requirements — not edge cases.

2. **Context is now a cost line item, not just a quality lever.** Bootstrap re-injection waste (20–30% tokens), 14k-token tool schemas, premature compaction, and invisible token burn are cross-project complaints. *Action:* implement per-call token telemetry by default and progressive/disclosure-based tool loading.

3. **Memory safety must span sessions, workspaces, and agents.** Cross-conversation recall failure, memory poisoning via scraped content, session-history exposure through file tools, and per-session sandboxing demands converge. *Action:* design memory as an isolated, trust-tagged, policy-controlled subsystem from day one.

4. **Security hardening is moving from authentication to authorization and data-integrity.** API-key redaction, unreachable path policies, destructive-command denial, and MCP OAuth standardization signal the next compliance frontier. *Action:* ship leak-detectors, allowlists, and in-workspace forbidden-path support before users ask.

5. **Windows/desktop is a real deployment target, and it is breaking.** Installer file-locks, TUI crashes, black windows, text-selection regressions, and AV false positives appear across CoPaw, Hermes, LobsterAI, IronClaw, and OpenClaw. *Action:* CI coverage for Windows/ConPTY/installer paths is now a user-visible differentiator.

6. **Governance processes are scaling with success.** RFC pipelines (ZeroClaw), doc-truth CI (IronClaw, OpenClaw), and persisted-state compatibility gates (IronClaw epic #7380) indicate the ecosystem's operational maturity is catching up to its feature breadth. *Action:* budget for architecture-review and documentation-verification tooling proportional to agent count.

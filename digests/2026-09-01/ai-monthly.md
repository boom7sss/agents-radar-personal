## 二、CLI 工具月度进展

### 整体态势判断

AI CLI 工具已从"代码补全助手"演进为**多智能体协作、远程服务化的完整开发平台**。本月最重要的结构性信号是：**执行可靠性与透明度取代功能数量成为社区第一诉求**。各工具核心关注高度趋同：Windows 平台稳定性、MCP 协议兼容性、会话/上下文管理、subagent 可观测性与可靠性。

**四大核心矛盾**（贯穿全月）：
1. **资源消耗不透明**——会话限额无故消耗、缺失 prompt-caching 致 2.5 倍成本、Codex 单会话 5.9 小时烧掉 9.47M token
2. **执行可靠性**——挂起、误报完成、压缩丢失状态、静默失败
3. **平台支持短板**——Windows 体验（BSOD、CRLF、GPU 崩溃）与跨设备协同
4. **MCP 从"能连上"走向"生产级"**——OAuth 回调、stdio fd 泄漏、注册表策略等落地问题

## 四、技术趋势总结

### 1. 安全与合规成为第一优先级

- **EU AI Act（08-02 生效）** 直接驱动 Claude 文本水印机制公开、多厂商协同执行同一实践守则
- OpenAI 推出"零数据留存"选项，指向企业级隐私合规作为前沿模型商业化关键卖点
- 安全漏洞修复在各 CLI 工具中占比显著上升（Codex 8+ 漏洞、Gemini SSRF/符号链接/变量展开绕过、Copilot 权限绕过）
- 安全透明度成为竞争维度：Anthropic 两度自愿披露真实安全事故

### 2. 推理成本急剧下探，价格战初现

- GPT-5.6 Sol 降价 50%（08-18）
- GPT-5.6 Sol「Ultrafast」模式最高 14 倍推理加速（Cerebras 合作）
- 被普遍解读为对 DeepSeek 等低价模型的策略性回应
- 推理成本突破 + 低价模型竞争 → 定价策略进入新阶段

### 3. 多智能体编排从实验走向产品化，但可靠性滞后

- Claude Code 跨会话消息上线（08-09）、Subagent forking 默认开启
- Qwen Code `/coordinate` 原生多智能体命令
- Anthropic 多智能体系统风险报告发布
- 但：子代理误报、挂起、绕过授权、静默丢失贯穿所有工具——"自动化可信度"是最大共性痛点

### 4. 跨工具协作规范萌芽

- **AGENTS.md 开放标准**（4852👍）——支持跨工具统一代理指令规范，成为生态级共识诉求
- agent-plugins.org 规范（Pi 生态）
- 反映市场对"工具碎片化"的反制需求

### 5. 从代码生成到科学发现

- Claude 蛋白质结合剂从头设计（14/15 靶点成功率）
- Claude 发现密码学算法本身的数学缺陷（HAWK 后量子签名方案）
- 黎曼 zeta 猜想突破（67.2% vs 41.6%）
- AI 从"发现实现漏洞"迈入"发现数学原理级缺陷"新阶段

### 6. 执行可靠性与透明度取代功能数量成为第一诉求

- 所有 CLI 工具的核心矛盾高度趋同：成本不透明、可靠性不足、平台短板
- "稳定性攻坚期"取代"功能竞赛期"
